🎯 RESUMO EXECUTIVO

Implementadas 4 melhorias estratégicas que transformam a UX do ContaFácil MZ:

1. 🎨 Menu Inteligente — Reduz complexidade visual em 60%
2. 🔔 Notificações Automáticas — Alertas em tempo real (5 tipos)
3. 💳 Proteção de Crédito — Bloqueia vendas excessivas
4. 🚀 Onboarding Guiado — Conduz novos utilizadores (4 tarefas)

│ 1️⃣  MENU INTELIGENTE (Reorganização de Navegação)                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ ANTES: Menu linear com 20+ itens + overload visual                          │
│                                                                              │
│ DEPOIS: 5 seções organizadas por contexto de negócio                        │
│                                                                              │
│ Seção                 Itens      Ícone
│ ─────────────────────────────────────────

│ 🏢 EMPRESARIAL        7 itens    DRE, IVA, Folha de Salários
│ 👤 CONTA              2 itens    Perfil, Configurações
│                                                                              │

│                                                                              │

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2️⃣  NOTIFICAÇÕES AUTOMÁTICAS (Sistema Central de Alertas)                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ ANTES: Sem notificações. Utilizador vê problemas apenas se procurar         │
│                                                                              │
│ DEPOIS: Centro de notificações com 5 tipos de alertas                       │
│                                                                              │
│ Tipo de Alerta           Cor        Frequência      Exemplo                │
│ ──────────────────────────────────────────────────────────────────────────  │
│ 🔴 Estoque Crítico       Vermelho   Sempre          "Arroz esgotado!"      │
│ 🟡 Estoque Baixo         Amarelo    Sempre          "Sal < 5 unidades"    │
│ 🟠 Dívida Vencida        Laranja    Sempre          "João deve MT 5000"   │
│ 🟢 Caixa Aberto          Verde      Todos os dias   "Abrir caixa?"        │
│ ✨ Vendas Positivas      Azul       Motivação       "Ótimas vendas: MT xx!" │
│                                                                              │
│ 📍 LOCALIZAÇÃO: Ícone de campainha (🔔) no topbar, direito                  │
│ 🔄 AUTO-UPDATE: A cada 2 minutos (sem refresh manual)                      │
│ 📊 BADGE: Mostra contagem de alertas não lidos                             │
│                                                                              │
│ ✅ BENEFÍCIO: Negócio com inteligência embutida                            │
│              Reduz "surpresas" (stock out, dívidas)                        │
│              Aumenta tempo de reação para problemas                        │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 3️⃣  PROTEÇÃO DE CRÉDITO (Validação Inteligente no POS)                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ ANTES: Sem limite. Clientes acumulam dívidas infinitas                      │
│                                                                              │
│ DEPOIS: Bloqueio automático se cliente ultrapassa limite                    │
│                                                                              │
│ FLUXO NO POS:                                                               │
│ 1. Seleciona cliente (ex: "João Silva")                                    │
│ 2. Tenta finalizar venda (ex: MT 3000)                                     │
│ 3. Sistema verifica:                                                        │
│    ├─ Saldo actual de João: MT 5000 (deve)                                │
│    ├─ Limite de crédito: MT 5000 (config)                                 │
│    └─ Venda ultrapassaria: MT 8000 (5000 + 3000)                         │
│ 4. BLOQUEIO com alerta:                                                     │
│    "⛔ Cliente 'João Silva' atingiu limite de crédito.                     │
│     Saldo actual: 5.000,00 MT                                              │
│     Limite: 5.000,00 MT                                                    │
│     Compra ultrapassaria: 8.000,00 MT                                      │
│     Cobra em dinheiro, M-Pesa ou contacte o cliente."                      │
│ 5. Venda NÃO é registada (segura contra má dívida)                         │
│                                                                              │
│ ⚙️  CONFIGURÁVEL:                                                            │
│    • Limite padrão: 5.000 MT (editável em vendas.js linha 106)             │
│    • Por cliente: limiteCredito (propriedade da BD)                        │
│                                                                              │
│ ✅ BENEFÍCIO: Protege cash flow                                             │
│              Reduz WIP (bad debt)                                          │
│              Força negociação com cliente antes de venda                   │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

⚠️  NOTAS IMPORTANTES

1. SEGURANÇA
   • Validação de crédito é CLIENT-SIDE (UX only)
   • Backend DEVE revalidar em POST /vendas
   • Nunca confiar apenas em cliente.limiteCredito

2. PERFORMANCE
   • Notificações: 3-5 API calls / 2 min
   • Onboarding: localStorage read/write ~1ms
   • Sem impacto observável em dispositivos modernos

3. COMPATIBILIDADE
   • Requer: ES6+ (Chrome, Firefox, Safari, Edge recentes)
   • IE 11: Não suportado
   • Mobile: Testado em viewports 375px+

4. DEPENDÊNCIAS
   • state object (config.js)
   • apiFetch() function (config.js)
   • Chart.js v4.4.3 (já incluído)

📞 SUPORTE & DEBUGGING

Erro: "notificacoes-sistema is not defined"
→ Verificar se script está após navegacao.js no index.html

Erro: "initOnboarding is not defined"
→ Verificar se onboarding.js está no HTML

Notificações não aparecem
→ DevTools → Network → verificar se /dashboard/* retorna dados
→ Console → gerarNotificacoesSistema() → ver erro

Crédito não valida
→ Verificar cliente.saldoDevedor é number (não string)
→ Verificar cliente.limiteCredito existe

Onboarding não progride
→ Abrir DevTools → Application → LocalStorage
→ Procurar key "contafacil_onboarding_[userId]"
→ Verificar se estado é true para tarefas completas
